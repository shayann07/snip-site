Technical Architecture

Engineered without compromises.

A multi-module Kotlin Multiplatform project using modern Jetpack Compose, SQLDelight, and NDK C audio toolchains.

Component Specification Implementation Details
Decoding Engine MP3, AAC, FLAC, OGG, WAV Platform MediaExtractor + dedicated MediaCodec threads with PCM windowing
MP3 Encoder LAME 3.100 (C via NDK) CBR 128 / 192 / 256 / 320 kbps with ID3v2 tag generation
OGG Encoder libvorbis 1.3.7 + libogg 1.3.5 Variable quality float encoding with Vorbis comment framing
M4A Encoder MediaCodec AAC-LC Hardware-accelerated with EMUI 9 / Kirin csd-0 packet guards
ELF Alignment 16 KB Page Aligned (0x4000) Fully compliant with Android 15+ 16 KB kernel page requirements
Database SQLDelight + SQLite Zero-reflection local clip metadata persistence
UI Framework Compose Multiplatform Imperative playhead canvas, 60 fps Kirin 710 benchmarked drag physics
OS Compatibility Android 8.0+ (API 26 to 37) Tested on Huawei Y9 2019 (EMUI 9) and Pixel 10 Pro XL
