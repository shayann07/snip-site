Open-Source Licences

Snip includes the open-source components listed below. Their full licence notices follow.

How these components are used: Snip’s own code is proprietary. The MP3 encoder, LAME (LGPL 2.1), is built as its own shared library and dynamically linked, so it can be replaced. The Ogg Vorbis encoder (libogg and libvorbis) is used under its BSD-style licence. Every other component is listed with its licence below.

Index of Included Libraries

  • LAME 3.100 (MP3 Audio Encoding Engine) — GNU LGPL 2.1
  • Xiph.Org libogg 1.3.5 & libvorbis 1.3.7 (OGG Vorbis Audio Codec) — BSD-Style
  • Kotlin, Compose, AndroidX, Koin, Decompose, SQLDelight — Apache License 2.0
  • Schibsted Grotesk & JetBrains Mono Fonts — SIL Open Font License 1.1

1. LAME 3.100 — GNU Lesser General Public License (LGPL) v2.1

In Snip, LAME 3.100 is built as its own shared library, libmp3lame.so, which Snip loads through dynamic linking. You may replace libmp3lame.so with your own build of LAME. The complete corresponding source for the LAME library shipped in Snip — the LAME 3.100 sources and the exact build configuration used to compile them — is published at github.com/shayann07/snip-site/tree/main/lame. The upstream project is at lame.sourceforge.io.
